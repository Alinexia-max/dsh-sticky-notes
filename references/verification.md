# 安装后的人工核对清单

`node check-client.mjs` 只能做静态检查：工作区里没有 React/ReactDOM，也没有真实的 slot 环境，
样式、拖拽、主题、弹窗这些必须装进宿主里看。下面这份清单按「一眼能看出来」的顺序排，
每次改动客户端后照着走一遍，比盲改省事。

> 前置：`plugin_manager` → `install_bundle` 指向本目录绝对路径，重启面板后左侧栏出现便签图标。

## 1. 接入与外壳

- [ ] 左侧栏图标可见，悬停显示「便签 / Notes」，位置在「插件市场」之后、「计划任务」之前。
- [ ] 点开后主面板铺满中间区域，没有多出宿主自带的外框或双标题。
- [ ] 切换宿主明暗主题：面板底色、工具栏、弹窗跟着变；便签纸变成压暗配色 + 浅色字，字不糊。
- [ ] 面板窄到 700px 左右时，工具栏换行而不是被裁掉；按钮文字不重叠。

## 2. 基础编辑

- [ ] 「新建」后光标自动落在标题输入框；标题留空时卡片头部用正文首行当标题。
- [ ] 正文点一下进入原文编辑，光标落在点中的那一行；Esc 或点卡片外回到预览。
- [ ] `Tab` / `Shift+Tab` 在正文里缩进、回退两格。
- [ ] 右下角拖拽缩放有效，松手后尺寸被记住，刷新后仍是这个尺寸。
- [ ] 删掉最后一条提示「便签已删除」并给出撤销；6 秒内撤销能恢复。
- [ ] 切走另一张便签时，一个字都没写的空白便签会自动消失。
- [ ] 满 200 条时「新建」变灰，悬停提示上限。

## 3. 预览态与 Markdown

- [ ] 管道表格在预览里是真表格，点单元格就地改，Enter 提交、Esc 放弃。
- [ ] 从 Excel 复制一块区域粘贴，自动变成表格。
- [ ] `- [ ]` / `- [x]` 渲染成复选框，点击能写回；卡片底部显示完成度。
- [ ] `# 一级标题` … `###### 六级标题` 逐级变小，且不显示 `#`。
- [ ] `**粗体**`、`*斜体*`、`` `行内代码` `` 渲染成对应样式，符号本身不显示。
- [ ] `[文字](https://…)` 显示为下划线链接，点击在新标签页打开。
- [ ] 单独的 URL 仍会变成底部胶囊；正文里已经是 `[文字](url)` 的 URL 不再重复出胶囊。
- [ ] ``` 围栏代码块 ``` 渲染成等宽灰底块，块里的 `|` 不会被误判成表格。
- [ ] `- 项` / `1. 项` 渲染成无序/有序列表；缩进两格的子项有层级。
- [ ] 图片行 `![](assets/x.png)` 在正文里让位给底部缩略图，不重复显示原文。
- [ ] 预览里的长内容在卡片内滚动，不会把卡片撑高到超过最大高度。

## 4. 组织与查找

- [ ] 搜索框输入关键词后只剩匹配卡片，脚部显示「N 处匹配」。
- [ ] `Ctrl/⌘+F` 聚焦搜索并全选；`Ctrl/⌘+S` 立即保存；`Alt+N` 新建。
- [ ] 四种排序（手动 / 创建时间 / 最近编辑 / 标题）都生效，置顶的始终在最前。
- [ ] 拖拽卡片时有整卡拖影、落点竖条、重排有过渡动画；搜索状态下拖拽被禁用。
- [ ] 拖到置顶区 / 普通区会跟着换组。
- [ ] 图钉按钮能置顶/取消，置顶卡片常驻抬起阴影。
- [ ] 置顶与普通便签同时存在时，两组之间有一行小标题「置顶 n」「其他 n」，数字等于各组条数；
      全部置顶或全都不置顶时这行标题不出现。
- [ ] 工具栏「紧凑 / 宽松」点一下卡片默认尺寸与看板留白随之变化，刷新后保持上次选择（存在 localStorage）。
- [ ] 先手动拖大一张卡片再切密度：这张卡片的尺寸不变，没拖过的卡片跟着变。

## 5. 图片

- [ ] 粘贴截图会出现在卡片底部缩略图，点开新标签页能看到原图。
- [ ] 直接把图片文件拖到卡片上也能上传（拖拽排序不会误触发）。
- [ ] 超过 8MB 的图片提示「图片太大」。
- [ ] 拖非图片文件到卡片上不报错、不导航走。

## 6. 数据与备份（新增）

- [ ] 工具栏「数据」打开弹窗，三块内容都在：快照历史 / 导入导出 / 图片占用。
- [ ] 快照历史至少有 1 条「自动」；显示时间、条数、大小；`Esc` 和点遮罩都能关。
- [ ] 点「恢复」后卡片内容变成快照时的样子，弹窗顶部提示「已恢复快照: notes.bak.N.json」。
- [ ] 恢复后刷新快照列表，多出一条「恢复前」——回滚本身也能再回滚。
- [ ] 「导出 JSON」下载 `sticky-notes-<时间戳>.json`，用编辑器打开能看到 `format: "dsh-sticky-notes"`。
- [ ] 「导出 Markdown」下载 zip；解压后是 `sticky-notes.md` + `assets/`，图片在 Markdown 里能显示。
- [ ] 「导入…」选刚导出的 JSON：提示「已导入: +N / ~M」，卡片数量对应增加。
      后面可能再跟 ` · 已跳过无法识别的便签 K` 或 ` · 图片失败 K`，都是正常提示，不是报错。
- [ ] 导入同一个文件第二次：应当全部算「跳过」，不产生重复卡片。
- [ ] 本地已满 200 条时再导入一份含新便签的备份：本地原有便签**一条不少**，新增的进不来，
      提示变成「已导入: +0 / ~M · 超出上限未导入 N」，其中 `N` 是被拒的条数。想放进去就先删几条本地的。
- [ ] 图片占用显示「共 N 张 · 大小 · 孤儿 M 张」；有孤儿时「清理孤儿」可点。
- [ ] 清理后孤儿数变成 0，正文里仍被引用的图片显示正常（没被误删）。
- [ ] 刚粘贴一张图、立刻打开「数据」点「清理孤儿」：这张图不受影响（落盘不满 1 分钟不算孤儿），
      正文缩略图仍在；统计行里它会显示为「新上传」。
- [ ] 编辑正文后立刻点「清理孤儿」，不会因为「引用还没保存」把图删掉。
- [ ] 弹窗打开时「数据」按钮不重复弹、不卡住；操作期间按钮显示「处理中…」并禁用。

## 7. 回收站与目录

- [ ] 回收站列出被删便签、删除时间；还原能回到墙上，彻底删除会消失。
- [ ] 「清空回收站」要点两次，第一次文案变成「再点一次清空」。
- [ ] 「目录」显示当前路径；填绝对路径后迁移成功，提示条数与图片数。
- [ ] 填相对路径被拒绝；目标目录已有便签时提示「没有覆盖」。
- [ ] 「恢复默认」能把数据搬回默认目录。

## 8. 并发与模型接入

- [ ] 开两个窗口，A 改标题、B 改正文，两边都能保存，不出现「保存失败」死循环；其中一侧提示「已合并」。
- [ ] 通过 MCP 工具或另一个窗口改动后，切回面板（或 20 秒内）内容自动同步。
- [ ] 面板里有未保存改动时，外部改动不会直接冲掉正在写的内容。
- [ ] 关掉页面时不会把另一个窗口刚写的数据整份盖掉（不再出现「刚改的丢了」）。
- [ ] 在数据目录手工放一个 `.notes.lock`（内容随便写，把修改时间改到 1 分钟前），再点保存：
      应当正常写盘（10s 判陈旧、锁被回收），而不是一直 503「notes storage is locked」。
      删掉锁文件后重试也应当立刻恢复。

## 9. 异常数据（手工构造，可选）

- [ ] 把 `notes.json` 手工改成 201 条：面板能正常打开，显示 200 条，并提示「已跳过无法识别的便签: 1」；
      目录里**不会**多出 `notes.corrupt-*`（超量不该被当成文件损坏）。
- [ ] 把某一便签的 `id` 改成 `../x`：面板照常打开，这条被跳过并计入上面的提示。
- [ ] 导入一份含 `id: "../x"` 条目的 JSON：提示「已导入: +0 / ~0 · 已跳过无法识别的便签 K」，
      其余合法条目正常导入（面板的「导入…」固定走 `mode: merge`，只有接口层才用 `replace`）。
- [ ] 用 `mode: replace` 调一次 `POST …/import`，备份里放两条同 id 或一条 `id: "../x"`：
      返回 400（`error.proto.duplicateId` / `error.proto.invalidId`），墙上的便签**一条不少**。
- [ ] 把 `notes.json` 改成一段乱码：面板提示「已恢复」，并在目录里留下 `notes.corrupt-*`。
- [ ] 把某个 `notes.bak.1.json` 改成 `{"version":1}`（没有 `notes`）后在「数据」里点恢复：
      提示失败，墙上的便签**一条不少**。
- [ ] 正文写 `[截图](assets/<某张已有图片名>)`（没有感叹号）：卡片底部不出缩略图，
      但「清理孤儿」**不会**删掉那张图（普通链接也算引用）。
- [ ] 正文写 `![](assets/..)`：预览里这行显示为原文文本（既不出图也不凭空消失）。

## 10. 记录结果

把没通过的条目连同宿主版本、主题、窗口宽度记在下面，方便下次对照：

```
宿主版本:
主题:        light / dark
窗口宽度:
未通过项:
```
